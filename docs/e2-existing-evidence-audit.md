## Minimal E2 Questions and Evidence

The floor is one claim-scoped, independently reviewable packet per material class; this is coverage, not statistical power or permission to generalize beyond the named structures and method. LGEA (LLM-Guided Evidence Assessment) and DEA (Deterministic Evidence Assessment) receive the same immutable packet: claim, numeric criterion, scope, admissibility rules, provenance, reference domain, and follow-up options. Gold answers remain hidden. Both return `supported`, `contradicted`, or `unresolved`, cite evidence IDs, and explain missing numerics or limitations. DEA applies the frozen criterion and evidence ledger; LGEA returns a reasoned assessment.

For quantitative material claims, only complete, admissible, method-compatible numbers can support or contradict. Evidence supports if it meets the predeclared criterion beyond the numerical uncertainty; it contradicts if qualified evidence violates it beyond that uncertainty. Incomplete runs, missing values, mixed methods, contradictory qualified results, or uncertainty spanning the decision boundary require a justified `unresolved`. A failed calculation can support only a narrow claim about that record's failure, not a material property.
